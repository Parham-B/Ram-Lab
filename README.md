*آزمایشگاه رم، آیا رم بیشتر همیشه سیستم را سریع‌تر می‌کند؟*

این ابزار نشان می‌دهد چه زمانی افزایش رم کمک می‌کند و چه زمانی بی‌اثر است.
*راهنما:*
1. اجرا: فایل ram-lab.html را در مرورگر کامپیوتر یا گوشی باز کن. نصب و اینترنت لازم نیست.
2. در بخش «پیش‌بینی کن، بعد ببین» حدس بزن ارتقا چه اثری دارد، بعد نتیجه را ببین.
3. با دکمه‌ی «امتحانش کن در آزمایشگاه» همان حالت را بازی کن.
4. نوع کار، میزان رم، پردازنده و نوع هارد را عوض کن و نوارها و نمودار را دنبال کن.
5. بخش «Bottleneck کجاست؟» می‌گوید مشکل از کدام قطعه است.
6. چالش بودجه را حل کن: با بودجه‌ی مشخص، کدام ارتقا بهتر است؟
7. آزمون کوتاه آخر صفحه را جواب بده.
*نکته: اعداد و قیمت‌ها آموزشی و تقریبی‌اند. برای سیستم واقعی خودت، مصرف رم را در Task Manager ببین.*
